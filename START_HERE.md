# Start Here

Frontier Isles is a complete local V1 release candidate. For ordinary use:

```powershell
npm ci
npm run dev
```

For repository work, read `AGENTS.md`, `docs/PRODUCT_SCOPE.md`, `docs/GAME_RULES.md`, and
`docs/ARCHITECTURE.md` before the active task. Run `npm run check` before accepting a change.

Release verification, simulations, E2E setup, and static deployment are documented in:

- `docs/TESTING.md`
- `docs/RELEASE_CHECKLIST.md`
- `docs/DEPLOYMENT.md`
- `docs/KNOWN_LIMITATIONS.md`

Do not scaffold over this repository. The application, accepted contracts, and release tooling are
already present.
